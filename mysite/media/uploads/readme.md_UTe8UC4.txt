1. 게임 시작 방법 (How to Run the Game)
압축 풀기: 먼저, 받은 Build1008.zip 파일을 원하는 폴더에 압축을 풉니다.
게임 실행: 압축을 푼 폴더 안에서 AccountingGame.exe 파일을 더블 클릭하여 게임을 실행합니다.
필수 파일 확인: 반드시 AccountingGame.exe 파일과 AccountingGame_Data 폴더가 같은 위치에 있어야 합니다. 
구조가 변경되면 게임이 제대로 작동하지 않을 수 있습니다.

2. 게임 방법
  1) 게임이 실행되면 "Start Scene"가 나오면 "MainScene", "GameScene" 중에서 선택할 수 있다.
  2) "MainScene"을 선택하면 재무/투자/영업 활동을 재무상태표, 손익계산서, 현금흐름표로 만들어 지는 과정을 경험할 수 있다.
  3)  하단 오른 쪽 "Change" 버튼을 누르면 "MainScene" -> "GameScene" 으로 "", "GameScene"  -> "MainScene"으로 바뀐다.
  4)  "MainScene" -> "GameScene" 으로 씬이 바뀔 때 "MainScene"에 있는 데이터가 그대로  "GameScene" 으로 이전되어 
     회사의 재무제표 평가, 게임등에 사용된다. 
  5) 다시 "MainScene으로 복귀하여 회사의 활동을 계속할 수 있다.



3. 게임 종료 방법
  1) 상단 오른쪽 "EXIT" 버튼을 클릭한다. 또는 
  2) 상단 왼쪽 "FULL" 버튼을 클릭하면 화면이 크기 조정 가능한 화면이 되며 전체화면/부분화면을 선택 가능하고
      우측 상단에 "X"를 클릭하면 화면이 닫힌다. 


4. 시스템 요구 사항 (System Requirements)
운영 체제: Windows 7/8/10/11 (64비트),  Mac, Linux
프로세서: Intel Core i3 이상
메모리: 4GB RAM 이상
그래픽 카드: DirectX 11 호환 그래픽 카드
DirectX: 버전 11
저장 공간: 최소 500MB의 여유 공간

5. Windows, Mac, Linux 버전으로 빌드하였으나, Mac, Linux 에서는 테스트해보지 않아 실행 여부를 확인하지 못함.
  해상도 1920 x1080에 최적화되어 있습니다. 해상도가 변하더라도 조정되도록 하였으나 보장되지는 못합니다.
  태블렛, 모바일에서는 실행이 어렵습니다. 
   키보드 및 숫자 입력 등이 필요하나 모바일 버전에서는  별도의 UI가 필요하며 이것들을 만들지 못하였습니다.


6. 문제 해결 (Troubleshooting)

게임이 실행되지 않거나 오류가 발생할 경우, MonoBleedingEdge 폴더와 UnityPlayer.dll이 모두 같은 폴더에 있는지 확인해 주세요.
그래픽 카드 드라이버가 최신 버전으로 업데이트되어 있는지 확인하세요.
